# Guess-The-Song

An Android Studio project for the MEHFIL-E-RUBAROO "Guess the Song" game.

## Included
- Pick multiple MP3/audio files from the phone using Android's file picker.
- Music library displayed as a grid of named cards.
- Play only the first 5 seconds of a selected track.
- Separate guessing timer: 10, 12, or 15 seconds.
- Stop, replay, reveal answer, next song, and shuffle controls.
- Black, gold, and cream styling.
- No scoreboard.

## Build an APK
1. Install Android Studio (a recent stable version) and the Android SDK.
2. Open this folder in Android Studio.
3. Allow Gradle sync to finish.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the APK location when the build finishes.

The APK is not prebuilt in this archive; this is the Android project source. A local Android SDK/Gradle build environment is needed to compile it.
